# Reflection

One of the main challenges in this assignment was selecting the most suitable GitHub template. While multiple templates were available, choosing one that aligned with Agile principles required careful comparison. Another challenge was customizing the Kanban board. Adding appropriate columns such as "Testing" and "Blocked" required understanding the project workflow. Linking issues and assigning tasks also required attention to detail. Compared to other tools like Trello and Jira, GitHub Projects felt more integrated with development workflows since it directly connects to issues and repositories. However, it was less visually intuitive than Trello. Overall, this assignment improved understanding of workflow management and how Kanban boards support Agile development.
