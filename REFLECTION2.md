# Reflection

One of the biggest challenges I faced in this assignment was translating system requirements into use cases. At first, the requirements seemed clear because they described what the system should do. However, when I started creating use cases, I realized I had to think differently. Instead of focusing on the system itself, I had to focus on how users interact with it step by step. This made me rethink some of the requirements and break them down into smaller actions such as submitting text, processing it, and viewing results.

Another challenge was making sure everything stayed consistent across the project. The use case diagram, use case descriptions, and test cases all needed to match the requirements from the previous assignment. Sometimes I noticed I was using slightly different names for the same function, which could cause confusion. I had to go back and fix those to make sure everything aligned properly. This helped me understand how important consistency is in software documentation.

Writing the use case specifications was also a bit difficult, especially when defining preconditions, postconditions, and alternative flows. It required me to think carefully about what could go wrong, such as users entering invalid input or the system failing to process data. Although this took extra time, it helped me understand the system more deeply and made the design more complete.

Creating test cases was another challenging part. I had to make sure that each test case clearly matched a requirement and that the steps and expected results were easy to understand. Designing non-functional tests, like performance and security, was also new to me because it required thinking about real-world situations, such as many users using the system at the same time.

Overall, this assignment helped me see how requirements, use cases, and testing are all connected. It made me realize that building a system is not just about writing code, but also about planning, organizing, and making sure everything works together. Even though it was challenging, it was a valuable learning experience.
